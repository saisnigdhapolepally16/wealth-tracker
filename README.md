# Wealth Tracker

A personal finance tracking application built step-by-step as a full-stack learning project.

## Goals

- Track income and expenses
- Visualize financial data
- Learn full-stack architecture
- Add AI-driven financial insights later

## Tech Stack (Planned)

Frontend: React  
Backend: Node.js + Express  
Database: SQLite  
Charts: Chart.js  

## Project Structure

wealth-tracker
│
├ backend
├ frontend
├ database
└ docs

## Development Phases

Phase 0 — Project setup  
Phase 1 — Basic transaction tracking  
Phase 2 — Dashboard and analytics  
Phase 3 — Authentication  
Phase 4 — AI financial insights
